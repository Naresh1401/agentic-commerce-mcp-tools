# MCP Server for Commerce Tools

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Lightweight MCP-style JSON tool server exposing commerce tools with schema validation and role-aware permissions.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
